## 统一的文档骨架

两个专栏的每一篇都是同一套结构，方便横向对照和快速定位：

```
① 信息块      —— 视频标题 / UP主 / 时长 / 发布日 / 地址 / 来源说明
② 目录        —— 带锚点跳转
③ 第 0 章     —— 课程地图：这一集解决什么问题
④ 正文各章    —— 痛点/事故 → 为什么 → 解法 → 代码 → 坑
⑤ 全局视角    —— 把碎片拼成一张架构图
⑥ 速查卡      —— 命令/参数/对比表
⑦ 动手路线    —— 可执行的练习步骤
⑧ 面试自测    —— 折叠答案，先自测再看
⑨ 📌 补充     —— 视频没讲但会踩的坑
⑩ 一句话总结  —— 作者原话收尾
⑪ 附录        —— 本文信息
```

> 阅读约定：**正文即视频原意**；凡标注「📌 补充」的，都是原讲解之外的延伸内容。
